# Autonomous factory evolution

Continue the existing live runtime toward supervised, measurable self-improvement. Preserve current frontend edits and one coding session per request. T3 is now installed and reachable; model/GitHub execution still needs qualification.

1. Reliability: truthful terminal state, active-time accounting excluding human waits, bounded Temporal retries, activity heartbeats, atomic request leases, independent worker health/watchdog, safe reconciliation and deduplicated alerts.
2. Lifecycle profiles: explicit greenfield, brownfield and modernization contracts; context-aware skills; baseline/acceptance evidence; approved empty-repository bootstrap and modernization preservation/cutover requirements.
3. Learning: outcome evidence, structured retrospective proposals, immutable candidate versions, held-out paired evaluation, approval/activation/rollback; never modify policy or source from untrusted retrospective prose.
4. Operator controls and qualification: authenticated runtime/learning endpoints, runtime readiness, CI feedback boundaries, regression/fault tests and real T3 smoke in a disposable repository. Production release/deployment requires a declared environment adapter and authority; generic code changes cannot invent these.

Every slice requires failure-path tests. Independent monitoring never assumes that a live process implies meaningful task progress. Unknown side effects are reconciled by external identity and never retried blindly. Skills remain guidance, not a security boundary.
